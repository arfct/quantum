# Checkbox

Checkboxes select one or more items from a set, or turn an option on inside a form that is submitted. The consumer provides `label`, and `checked` with `onChange` (or `defaultChecked`).

- 18px box with a 2px `text-medium` border; checked fills `secondary` with an `on-secondary` check.
- 40px state circle around the box for hover and focus overlays.
- Use a Switch instead when the change takes effect immediately.
