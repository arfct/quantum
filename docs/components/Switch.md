# Switch

Switches toggle a single setting on or off, taking effect immediately. The consumer provides `label` and `checked` with `onChange` (or `defaultChecked`).

- 36 × 14px track at `on-surface` 38%; 20px thumb with `shadow-1`. When on, thumb and track take `secondary` (track at 54%).
- The input carries `role="switch"`; the label names the setting, not its state.
- Use a Checkbox inside forms that need a submit step.
