# Fab

The floating action button carries the single most important action on a screen. The consumer provides an `icon`, plus `label` for an extended FAB or `aria-label` for an icon-only one.

- 56px disc in `fab` (red) with an `on-fab` icon, `shadow-6`, `shadow-12` when pressed.
- `mini` (40px) when space is tight; extended (48px tall, with a label) when the action needs words.
- One FAB per screen. Not for destructive or minor actions (delete, share, archive).
- Placed 16px from the screen edge on mobile, 24px on larger screens.
